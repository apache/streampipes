Transformation scripts

A transformation script runs once for every incoming event. Your script expose a callable transform function with the signature transform(event, out, ctx).

  • event: The event contains the current input payload and its available runtime fields.
  • out: The output collector provides out.collect(...) to emit transformed events.
  • ctx: The context provides access to the StreamPipes client through ctx.client().
